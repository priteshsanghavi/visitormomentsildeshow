
# ASSUMPTIONS

## Project Name
Visitor Moments - Visitor Photo Slideshow System

## Project Assumptions

1. Visitors can register using their name, email address and mobile number.

2. Email address and mobile number are used to identify returning visitors.

3. Visitors must provide consent before uploading their photographs.

4. Returning visitors can upload additional photographs using their existing visitor details.

5. Visitors can upload multiple photographs in one submission.

6. Only JPG, JPEG, PNG and WEBP image formats are accepted.

7. Each uploaded image must not exceed 5 MB.

8. A maximum of 10 images can be uploaded in one submission.

9. Newly uploaded photographs are assigned Pending status by default.

10. The administrator is responsible for approving or rejecting uploaded photographs.

11. Only approved photographs are displayed in the public slideshow.

12. Rejected photographs are not displayed in the slideshow.

13. The slideshow interval is configurable by the administrator between 2 and 60 seconds.

14. The default slideshow interval is 5 seconds.

15. The administrator can enable or disable the slideshow.

16. The system is developed for a single organization or display screen.

17. The administrator accesses the management panel using a registered admin account.

18. The project is developed using PHP, MySQL, HTML, CSS, JavaScript and Bootstrap 5.

19. XAMPP is used as the local development environment.

20. Internet access is required for loading Bootstrap and Bootstrap Icons from their CDN links, and for loading Chart.js.

## Limitations

- The system currently supports image uploads only, not videos.
- The project is designed for local XAMPP deployment.
- Email verification and SMS OTP verification are not implemented.
- The slideshow requires an internet-connected browser for externally hosted libraries.
